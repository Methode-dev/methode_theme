# Aura Backend Theme

Premium backend theme for Odoo 19 Community Edition.

## What it includes

- Customized backend branding and color variables
- Login page styling
- Top navigation bar and loading experience
- App menu and dashboard improvements
- Form, list, kanban, chatter, and activity view styling
- Frontend and backend asset overrides

## Installation

1. Copy the `aura_backend_theme` module into your Odoo addons path.
2. Update the app list from Odoo Apps.
3. Install the module from the Apps menu.

## Notes

- The `Design.md` and plan files are reference documents for development.
- They are not required for the module to work in production.
- This README is for the backend theme module only; the Community Edition and Free modules keep their own documentation.
- Home Dashboard KPI cards and shared widgets are scoped to the active company in multi-company setups.
