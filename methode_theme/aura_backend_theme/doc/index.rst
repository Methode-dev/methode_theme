==========================================
Aura Backend Theme - Community Edition
==========================================

Aura Backend Theme is a backend UI theme for Odoo 19 Community that improves
navigation clarity, branding consistency, and day-to-day usability across core
business apps.

Features
========

The module includes:

* Branded topbar and sidebar layout
* Customizable login page variants (including split-panel mode)
* Theme settings dialog for brand and interface options
* Refined list, form, kanban, calendar, and discuss views
* Inventory and status bar visual improvements
* Company-level theme preferences

Installation
============

To install this module:

* Copy the module into your custom addons path
* Restart the Odoo server
* Update the Apps list
* Install ``Aura Backend Theme - Community Edition``

Configuration
=============

After installation, open Settings and configure:

* Brand color and related surface accents
* Topbar and sidebar style options
* Login layout, copy, and background behavior
* Loading indicator style

Usage
=====

Once enabled, Aura styles the Odoo backend shell and key business views. Use
the theme settings dialog to adapt the experience per company branding.
